## 1. 产品功能全景

### 1.1 版本规划

| 版本 | 时间 | 范围 | 目的 |
| --- | --- | --- | --- |
| MVP | 2026-09 ~ 12 | 教师端核心备课闭环 + 管理端基础 + 埋点 | 试点部署、采集真实数据 |
| V2 | 2027-01 ~ 02 | 学情分析、教研广场、语音输入 | 商业计划书亮点、省赛展示 |
| V3 | 2027-03 ~ 08 | 教育局大屏、多学科扩展、内容审核强化 | 国赛网评与现场赛 |

### 1.2 功能矩阵（按角色 × 模块）

| 模块 | 教师端 | 管理端 | 支撑系统 |
| --- | --- | --- | --- |
| 登录注册 | 微信/手机号一键登录 | 账号管理 | Sa-Token + JWT |
| 备课 | 教案生成/编辑/导出、AI 对话、语音输入 | 模板管理 | 生成管线（见文档 03） |
| 习题 | 按知识点/难度/题型生成、组卷 | 题库管理 | 结构化输出 + 校验 |
| 资源库 | 校本资源/精品教案/收藏/乡土案例 | 知识库运营 | RAG + 标签体系 |
| 学情（V2） | 班级学情报告、薄弱点、备课建议 | 区域学情看板 | 数据导入 + 分析 |
| 教研（V2） | 教研广场、集体备课、同课异构 | 教研活动管理 | 社区 + 协作 |
| 数据 | 个人使用报告 | 数据大屏、运营分析 | 埋点 + 聚合 |
| 审核 | 生成内容即时反馈 | 抽检、敏感词、日志 | 内容安全 |
| 系统 | 帮助、设置 | 模型配置、限流、权限 | 多模型路由 |

### 1.3 MVP 验收标准（可演示清单）

1. 教师 3 分钟内从"登录"走到"生成一份完整教案"；
2. 教案含课标依据卡片（2022 版课标条目），可修改、可导出 Word；
3. 同一课题二次生成有差异（可配置）；
4. 生成过程有流式打字机效果，弱网可重试；
5. 管理端能看到每日使用数据并导出；
6. 全程埋点可统计"备课时长"。

### 2.2 核心页面详设

#### 2.2.1 新建备课向导（体验关键页）

- **Step 1 选学科年级**：大卡片宫格，一键直达；默认记住上次选择；
- **Step 2 教材单元**：左侧教材目录树（人教/北师大/苏教等版本可切换），右侧选中课题预览，支持搜索；
- **Step 3 填要求**：课型（新授课/复习课/公开课/习题课）、篇幅（简案/详案）、风格（常规/生动/乡土化）、补充要求（文字输入或语音）；
- **Step 4 生成中**：流式打字机 + 步骤提示（正在定位课标…正在检索教案模板…正在生成教学目标…），弱网自动重试；可"跳过等待，完成后通知"；
- **成功**：自动进入教案编辑器；**失败**：展示原因 + 一键重试 + 降级为通用生成。

#### 2.2.2 教案编辑器（评委演示主页面）

- **顶栏**：标题、学科/年级/教材标签、质量分（如 92 分）、操作按钮（重新生成 / 导出 / 收藏 / 反馈）；
- **区块导航（左/上）**：7 大区块，点击定位；每区块独立"重新生成 / 修改"；
- **教学目标区**：核心素养目标（知识/能力/素养）+ 课标依据卡片（展开显示课标原文条目）——这是最抓眼球的差异化点；
- **教学过程区（时间轴）**：环节卡片可上移/下移/插入/删除/单独重写；每环节标注时长与师生活动；
- **板书设计区**：结构化板书（可切换文字/简易图示）；
- **作业设计区**：分层作业（基础/提高/拓展），可"一键生成配套习题"；
- **AI 对话浮窗**：预设指令（改生动些 / 加小组活动 / 换成乡土案例 / 出课堂提问 / 简化语言），也可自由输入或语音；对话结果可"应用到教案"；
- **导出预览**：Word / PDF 双格式，模板美观（学校用标准教案模板风格）。

#### 2.2.3 数据看板（管理端，路演素材）

- 指标卡：教师数、累计生成量、日活、节省备课时长、好评率；
- 图表：生成量趋势（折线）、学科分布（饼）、区域分布（河南地图）、功能使用热力（矩形树图）、教师留存（漏斗）；
- 支持一键导出周报/月报（省赛佐证材料直接可用）。

## 4. 关键交互与状态设计

| 状态 | 表现 | 兜底 |
| --- | --- | --- |
| 生成中 | 流式打字机 + 步骤提示 | 弱网自动重试，最长 120s 超时 |
| 生成失败 | 原因卡片（网络/模型/内容） | 一键重试 / 降级通用模式 / 完成后通知 |
| 内容不合规 | 审核提示 + 修改建议 | 记录日志，管理员介入 |
| 无网络 | 缓存优先 + 队列待发 | 断点续传，弱网模式提示 |
| 教师反馈 | 一键"用得上/需修改" + 留言 | 回流知识库与模板优化 |

## 5. 视觉与体验规范

- **品牌色**：暖橙 + 麦绿（乡土感 + 教育温度），避免冷冰冰的科技蓝；
- **字体与排版**：正文 ≥ 15px，教案正文行距 1.6，适合教师长时间阅读；
- **适老化/低配置**：兼容 3 年前的千元机，弱网模式自动压缩图片与接口体积；
- **一键直达**：所有高频操作 ≤ 3 次点击完成；
- **可访问性**：支持系统字体放大、语音朗读教案正文（V2）。

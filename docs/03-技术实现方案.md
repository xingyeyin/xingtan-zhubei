# 「杏坛智备」技术实现方案（v0.1）

> 配套文档 01：完整架构 / 02：产品功能与页面 / 04：评审策略与备赛材料

---

## 1. AI 服务架构

```text
教师端/管理端
   │ REST / SSE
   ▼
Spring Boot（ai 模块）
   ├── 意图理解（学科/年级/教材/课题/课型/需求 结构化提取）
   ├── 知识定位（课标条目 + 教材单元 + 案例 召回）
   ├── 分节生成（目标→重难点→过程→作业，逐节生成+校验）
   ├── 质量校验（JSON Schema + 规则评分 + LLM 复核）
   └── 内容安全（敏感词 + 规则 + 人工抽检）
   │
   ├── Spring AI ChatClient（DeepSeek / 通义 双供应商路由）
   ├── RAG 管线（向量 + 关键词混合检索 → 重排 → 上下文压缩）
   ├── PostgreSQL + pgvector（知识库）
   ├── Redis（会话/队列/缓存/限流）
   └── MinIO（教案附件、导出文件、图片）
```

## 2. 知识库构建

### 2.1 课标库（差异化核心）

- 范围（MVP）：2022 版义务教育课程方案 + 语文/数学/英语课标；
- 结构：课标 → 学段 → 学习任务群/领域 → 内容要求 → 学业要求；
- 入库流程：PDF 解析 → Markdown 结构化 → 人工校对 → 分块（按条目）→ embedding；
- 生成时定位：根据"学科+年级+课题类型"先定位课标条目，生成"课标依据卡片"。

### 2.2 教材目录库

- 覆盖：人教版语文/数学/英语 1~9 年级 + 北师大/苏教数学（MVP），其余版本 V2；
- 形式：结构化 JSON（册 → 单元 → 课题 → 页范围 → 知识点标签）；
- 作用：目录树导航 + 检索过滤 + 生成上下文定位。

### 2.3 模板库

- 分学科 × 课型 × 篇幅 的教案模板（结构化区块 + 提示词）；
- 版本化管理，教师反馈可触发模板迭代。

### 2.4 乡土案例库

- 预置 100+ 河南/新乡案例条目（历史、地理、非遗、农事、人物）；
- 按学科/年级/主题打标签，生成时作为情境导入素材召回；
- 试点学校可共建扩充（教师上传 → 审核入库）。

## 3. RAG 检索管线

```text
查询 → 意图结构化
   → 向量检索（pgvector，HNSW 索引，TopK=30）
   → 关键词检索（PostgreSQL tsvector，TopK=30）
   → RRF 融合排序 → 重排（可选 BGE-reranker，TopK=8）
   → 上下文压缩（截断 + 去重 + 加引用标签）
   → 拼接送入生成
```

- 元数据过滤：学科/年级/教材版本/课型 提前过滤，减少噪声；
- 分块策略：课标按"条目"，教材按"课题"，教案按"区块"，案例按"主题"；
- 缓存：相同"学科+年级+教材+课题"的检索结果缓存 24h。

## 4. 生成管线（多步 Agent 化）

### Step 1 意图理解

- 输入：学科、年级、教材、课题、课型、篇幅、风格、补充需求；
- 输出：结构化任务对象（JSON），缺失项自动补默认值。

### Step 2 知识定位

- 课标条目召回 + 教材单元定位 + 模板选择 + 乡土案例召回；
- 拼装生成上下文（含引用来源，供"课标依据卡片"展示）。

### Step 3 分节生成

- 顺序：教学目标 → 重难点 → 教学准备 → 教学过程 → 板书 → 作业；
- 每节独立调用（上下文携带前节结果），保证一致性；
- 教学过程生成后校验"环节-时长"总和是否合理（40/45 分钟制）。

### Step 4 质量校验与重试

- 规则校验：JSON Schema 完整性、必填字段、时长合理性、字数范围；
- 评分模型：结构完整度（40%）+ 课标覆盖（30%）+ 情境贴合（20%）+ 可操作性（10%），输出质量分；
- 不达标：携带错误信息重试 1 次；仍不达标：降级为通用模式并标记。

### Step 5 输出

- 流式 SSE 返回（打字机效果）；同时落库 generation_task + lesson_plan；
- 前端展示质量分与课标依据卡片。

## 5. 结构化输出与 JSON Schema

- 所有生成结果用 JSON Schema 约束（Spring AI 结构化输出 / 提示词强约束 + 解析兜底）；
- 教案对象示例：

```json
{
  "title": "《背影》第一课时",
  "subject": "语文",
  "grade": 8,
  "textbook": "人教版八年级上册",

  "keyPoints": ["…"],
  "difficultPoints": ["…"],
```

## 6. 异步任务与流式输出

- generation_task 表 + Redis 队列；前端 SSE 订阅进度；
- 超时/失败状态机：PENDING → RUNNING → SUCCESS / FAILED / TIMEOUT；
- 弱网适配：前端断线自动重连查询任务状态，完成后拉取结果。

## 7. 导出实现

- Word：poi-tl 模板渲染（学校标准教案模板样式）；
- PDF：OpenPDF 渲染导出；
- 导出文件入 MinIO，返回下载链接（带时效签名）。

## 8. 埋点与看板

- 埋点事件：生成请求/成功/失败、编辑次数、导出、收藏、反馈、登录、任务耗时；
- usage_log 明细表 + 定时聚合到 stats 汇总表（小时级）；
- 管理端 ECharts 可视化：趋势、学科分布、区域地图、功能热力、留存漏斗；
- 关键指标：平均备课耗时（生成+编辑）、节省时长估算（对比基线调研）、质量分均值、反馈好评率。

## 9. 成本控制与稳定性

| 手段 | 说明 |
| --- | --- |
| 结果缓存 | 相同任务参数命中缓存直接返回（带版本失效策略） |
| 模型分级 | 简单任务（习题、问答）用低成本模型，复杂任务（详案）用旗舰模型 |
| 上下文压缩 | 控制 token 用量，长历史自动摘要 |
| 双供应商 | DeepSeek + 通义自动容灾切换 |
| 限流 | 单用户并发、全局 QPS、日配额（管理员可调） |
| 免费额度 | 优先使用各平台免费/低价档位 |

## 10. 安全与合规

- 内容安全：敏感词库 + 规则校验 + LLM 复核 + 人工抽检四层；
- 数据合规：教师信息最小化收集，教案数据匿名化统计；
- 未成年人保护：平台面向教师，内容面向教学场景，涉学生数据不落地；
- 账号安全：Sa-Token + JWT + 操作日志。

## 11. 测试与质量

- 单元测试：核心工具、校验规则、评分模型；
- 接口测试：生成管线全链路（mock 模型）；
- 回归用例：40+ 条典型教案生成用例（学科×课型×篇幅矩阵）；
- 验收：MVP 验收清单（见文档 02）逐项通过。

## 1. 红旅·创意组评审维度拆解与打法

| 维度 | 权重倾向 | 我们怎么拿分 |
| --- | --- | --- |
| 教育维度 | 高 | 真实调研故事、支教实践、团队成长、家国情怀；技能与大赛互哺的叙事 |
| 创新维度 | 高 | 新课标对齐引擎、教材版本适配、乡村场景引擎、教师共创数据飞轮、成效度量体系（软著/专利佐证） |
| 团队维度 | 中 | 3 人跨学科 + 指导老师 + 企业顾问；分工互补、执行力证据 |
| 实践实效 | 高 | 试点 2~3 所乡村学校、真实使用数据、备课时长对比、合作协议与感谢信 |
| 社会价值 | 高 | 教育公平叙事、可复制推广模式（新乡 → 河南 → 中西部）、公益可持续商业模式 |

> 核心逻辑：**评委最怕"PPT 项目"，最认"真落地 + 可量化 + 可复制"**。我们的每一张材料都必须有真实数据背书。

## 2. 五大创新点（包装话术）

1. **新课标对齐引擎**：教案核心素养目标逐条映射 2022 版课标条目，生成"课标依据卡片"——同类 AI 备课工具没有；
2. **教材版本自适应**：多版本教材目录结构化 + 页面级知识定位，换版本不换体验；
3. **乡村场景引擎**：弱网模式、低配手机适配、语音输入、乡土案例库（河南/新乡素材）——为乡村教师而设计，不是通用工具的移植；
4. **教师共创数据飞轮**：教案入库 → 校本知识库 → 跨校教研共享 → 数据反哺模板与推荐，"用得越多越好用"；
5. **成效度量体系**：备课耗时、质量分、满意度、区域看板全链路可量化，项目效果不是"感觉好"，而是"数据证明"。

## 3. 实践与数据计划

### 3.1 试点布局

- 试点 1（2026-12）：新乡周边乡村小学（1 所，30+ 教师）；
- 试点 2（2027-02）：第二所小学或初中（跨县，验证可复制性）；
- 试点 3（2027-05）：教育局/教体局合作意向，区域推广验证。

### 3.2 调研与量化

- **基线调研（2026-10~11）**：问卷 100+ 教师，统计备课时长、代课科目数、资源获取方式、痛点排序；
- **成效对比（2027-03）**：同批教师使用前后"平均备课时长"对比 + 教案质量评分对比；
- **月度报告（每月）**：活跃教师数、生成量、好评率、节省时长估算、典型使用案例；
- **访谈与故事**：3~5 位教师深度访谈（文字+视频授权），用于路演与 BP。

## 5. 路演 Demo 脚本（8 分钟版）

1. **故事开场（1 分钟）**：放一段调研视频/照片——一位教 3 门课的乡村老师说"备课靠抄教参，来不及教新课标"；
2. **痛点数据（1 分钟）**：基线调研结果（X% 教师备课超 2 小时、Y% 一人多科）；
3. **解决方案（30 秒）**：一句话 + 架构图（不展开技术细节）；
4. **现场 Demo（3 分钟，高潮）**：
   - 用低配手机 + 弱网模式；
   - 语音输入课题"《背影》第一课时"；
   - 流式生成，展示课标依据卡片（展开课标原文）——全场亮点；
   - AI 对话："换成乡土案例导入"→ 应用；
   - 一键导出 Word；
5. **真实数据（1.5 分钟）**：试点看板（教师数、生成量、备课时长对比、好评率）+ 教师访谈金句；
6. **模式与愿景（1 分钟）**：公益免费 + 增值服务 + 政府采购；新乡 → 河南 → 中西部推广路径；
7. **结尾（30 秒）**：金句 + 团队合影/实践照片。

> 演示脚本要点：**评委可能现场出题**，提前准备"任意课题快速生成"的兜底流程，保证 100% 不翻车。

1. 项目概述（一句话 + 赛道 + 团队）
2. 市场与痛点（乡村教师数据、政策背景：教育数字化/城乡均衡/新课标落地）
3. 调研与洞察（基线数据）
4. 产品与解决方案（功能 + 创新点 + 技术架构一页图）
5. 商业模式（公益免费基础版 + 学校增值服务 + 教育局采购 + 公益基金/企业 CSR）
6. 运营与数据（试点成果、留存、成本）
7. 团队与资源（成员 + 指导老师 + 顾问）
8. 发展规划（12 个月/36 个月路线图）
9. 社会效益（教育公平、乡村振兴、可复制性）
10. 风险与应对

## 7. 商业与可持续模式

- **基础版（公益免费）**：乡村教师无限量基础备课，教育局/学校 0 成本接入；
- **增值服务**：校本知识库、学情分析、教研数据报告（按校年费）；
- **政府采购**：对接"乡村教育数字化""城乡义务教育均衡"项目；
- **公益资金**：教育公益基金会、企业 CSR 赞助（降低乡村学校负担）；
- **数据价值**：脱敏后的教研数据洞察报告（区域教育管理部门）。

## 8. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 试点单一、说服力弱 | 布局 3 所不同区域学校，验证可复制 |
| 被质疑 AI 套壳 | 现场演示课标依据 + 教材版本适配 + 乡村场景功能 |
| 大厂同类产品竞争 | 差异化定位：乡村场景 + 课标对齐 + 公益模式 + 教师共建 |
| 数据不足 | 埋点先行，MVP 即采集；材料阶段只讲真实数据 |
| 团队人力 | 3 人核心 + 指导老师 + 企业顾问；开发砍功能保体验 |
| 评委现场出题 | 兜底流程 + 备用低配模型 + 预演 20 个冷门课题 |

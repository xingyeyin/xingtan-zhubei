# 试点学校部署指南（SOP）

> 配套：deploy/docker-compose.yml、deploy/nginx.conf、db/init.sql
> 目标：从"本地演示"到"学校真实可用"，并拿到可写入商业计划书与路演的真实数据。

---

## 1. 试点学校怎么谈

### 1.1 找谁

- 第一选择：指导老师 / 学校团委 / 教务处有合作关系的乡村小学、初中；
- 第二选择：师范类院校实习基地、支教组织、乡镇中心校；
- 第三选择：当地教育局（教体局）信息化科室，争取"教育数字化试点"名义。

### 1.2 带什么去谈

- 可运行的 Demo（手机 H5 即可，现场生成一份教案）；
- 一页纸项目介绍（痛点数据 + 产品截图 + 免费承诺）；
- 合作协议模板（试点校盖章，明确：免费试用 1 学期、数据脱敏使用、可随时退出）；
- 安全保障说明（数据加密、不采集学生个人信息、内容审核机制）。

### 1.3 谈成后要拿到的"材料"

- 试点合作协议（盖章）；
- 教师注册名单 / 使用许可；
- 基线问卷（使用前）；月度使用数据（使用中）；感谢信（使用后）；
- 教师访谈视频 / 文字授权；
- 现场照片、培训照片（用于路演）。

---

## 2. 部署方式（二选一）

### 2.1 方式一：云服务器 + Docker（推荐正式试点）

1. 购买阿里云轻量应用服务器（2C4G 即可，学生优惠约 100~300 元/年）；
2. 安装 Docker 与 Docker Compose；
3. 上传本项目到服务器，`cd deploy`，`cp .env.example .env` 并填写 API Key；
4. 执行 `docker compose up -d --build`；
5. 配置域名 + HTTPS（Nginx 已预留 443，用 Let's Encrypt 免费证书）；
6. 验证：`curl https://你的域名/api/admin/ping`。

### 2.2 方式二：本机开发环境（PostgreSQL 直连）

1. 安装 PostgreSQL 16（含 pgvector 扩展）；
2. 执行 `psql -U postgres -f db/init.sql`；
3. 后端以 `postgres` profile 启动（`mvn -pl application -am spring-boot:run -Dspring-boot.run.profiles=postgres,local`，需先补充该 profile 配置或使用环境变量覆盖数据源）。

## 3. 上线检查清单

- [ ] `.env` 已配置数据库密码、MinIO 密钥、大模型 API Key（不提交 Git）；
- [ ] 修改默认账号密码，关闭演示账号或改为真实教师账号体系；
- [ ] HTTPS 生效，`/api` 反代正常，SSE 未被缓冲（Nginx 已配置 `proxy_buffering off`）；
- [ ] 数据库每日备份任务已启用（见 deploy/backup.ps1）；
- [ ] MinIO 对象存储可访问，导出文件可下载；
- [ ] 内容审核：敏感词规则开启、人工抽检流程明确；
- [ ] 埋点数据可查看（管理端仪表盘有数字）。

---

## 4. 数据采集规范

- 埋点事件：登录、生成、编辑、导出、收藏、反馈（后端已实现 usage_log）；
- 周报模板：活跃教师数、生成量、好评率、节省时长估算、典型使用案例；
- 调研问卷：使用前（基线）+ 使用后（对比），各 100+ 份目标；
- 隐私：不采集学生个人信息，教师数据脱敏统计，合作协议中明确授权范围。

---

## 5. 常见问题

- **生成慢/失败**：检查 API Key 余额、网络；系统已做失败重试与降级；
- **弱网**：教师端弱网模式会自动压缩请求，生成过程可"完成后通知"；
- **教师不会用**：培训 30 分钟 + 图文教程 + 微信群答疑；
- **担心 AI 内容质量**：教案可编辑，附课标依据卡片，教师可一键反馈，后台可抽检。

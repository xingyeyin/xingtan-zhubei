**路演要点**

- 开头 30 秒决定印象分：先讲"人"（调研见到的老师），再讲数据；
- Demo 必须真实、不切屏：提前预演 20 个冷门课题，保证现场出题不翻车；
- 每次提到数据都要给出处（教育部统计公报、特岗计划、乡村教育研究）；
- 结尾留白，不堆砌内容。

### 1.1 现场演示双亮点（详细操作脚本）

**亮点一：30 秒生成对齐课标的教案（约 2 分钟）**

1. 手机（或投屏浏览器）打开教师端，登录演示账号；
2. 首页点"新建教案"→ 选语文/八年级/人教版 → 输入《背影》第一课时（或评委现场指定课题）；
3. 语音输入或打字，点"开始生成"，流式等待约 30 秒；
4. 展开**课标依据卡片**（强调：每条设计都能对上 2022 版课标）；
5. 点"AI 对话"现场改一个要求（如"换成乡土案例导入"），展示即时修改；
6. 点"导出PPT"，展示 AI 美化课件文件。

**亮点二：课件导入 → AI 分析 → 美化课件（约 1.5 分钟，本场差异化亮点）**

1. 从"我的备课"进"导入课件"；
2. 现场拖入/选择一份准备好的课件文件（建议用老师真实的旧 PPT，`.pptx` 或 PDF）；
3. 展示 AI 分析结果（核心内容、重难点、教案建议、PPT 大纲）；
4. 点"🎨 生成美化课件"→ 约 30 秒产出 12~16 页品牌化美化 PPT；
5. 强调："老师不用从零做课件，把旧课件交给 AI 就能升级成新课标课件。"

**演示备用方案（防翻车）**

- 若现场网络慢/API 超时：提前在手机/浏览器缓存好 1 份生成成功的教案和 1 份美化 PPT 文件，改为"展示已生成成果 + 后台录屏"；
- 若评委出冷门课题：用预演的 20 个课题兜底流程（语音输入 + 等待 + 展示）；
- 若课件导入失败：改用内置示例课件（仓库 软著材料/截图 或 uploads 示例），或直接用第 4 页已有的教案截图。

**现场演示检查清单**

- [ ] 演示账号可登录、API Key 有额度；
- [ ] 网络可用（现场 Wi-Fi + 手机热点双备）；
- [ ] 示例课件文件已放在桌面/收藏夹（PDF 或 PPTX，约 1~2MB）；
- [ ] 提前录好 2 段备份视频（教案生成 + 课件美化各 1 段）；
- [ ] 全流程彩排 ≥ 3 次，含评委出题模拟。

## 3. 答辩题库（20 题）

### 3.1 产品与技术

1. **为什么不是通用大模型套壳？**
   → 新课标对齐引擎（课标依据卡片）、教材版本自适应（75 册目录、9 科课标）、乡村场景引擎（弱网/语音/乡土案例）、教师反馈数据飞轮，四层差异化。
2. **教案质量怎么保证？**
   → 课标强约束提示词 + 结构化输出校验 + 质量评分（结构 40%+课标 30%+情境 20%+可操作 10%）+ 教师反馈闭环 + 人工抽检。
3. **模型成本会不会失控？**
   → 多供应商路由、结果缓存、分级调用（简单任务用低成本模型）、限流与配额。
4. **生成失败怎么办？**
   → 失败重试、降级通用模式、任务状态机与"完成后通知"。
5. **数据安全与隐私？**
   → 教师信息最小化收集、教案数据脱敏统计、不采集学生个人信息、内容审核四层防线。
6. **为什么覆盖这么多学科？**
   → 已入库 9 科 75 册目录 + 9 科课标（语数英 + 物理/化学/生物/道法/历史/地理），知识库可配置，验证课标对齐机制后可继续复制到其他学科。

### 3.2 市场与商业

7. **市场规模多大？** → 1069.76 万义务教育专任教师、18 万所学校；特岗计划 20 年补充 118 万人，乡村需求长期存在。
8. **和大厂 AI 教育产品比有什么优势？** → 专注乡村场景、公益免费可负担、课标对齐、教师共建、真实数据可量化。
9. **怎么赚钱？** → 学校版年费 + 区域政府采购 + 公益合作；基础版永久免费。
10. **获客渠道？** → 学校团委/支教组织/教育局信息化科室 + 指导老师校企资源。

### 3.3 运营与落地

11. **试点成果？** → 计划 2026-12 试点 1，2027-02 试点 2（跨县），以真实使用数据汇报。
12. **怎么证明真的有用？** → 基线调研（备课 2~3 小时）与使用后对比，目标下降 50%+；周留存 ≥40%。
13. **教师不会用怎么办？** → 30 分钟培训 + 图文教程 + 微信群答疑 + 弱网/语音适配。

### 3.4 团队与赛道

14. **团队构成？** → 软件工程专业两人 + 待补经管/设计一人 + 指导老师；跨专业补强计划明确。
15. **为什么是红旅赛道？** → 立足乡村振兴与教育公平一线真问题，产品可落地、可复制、可量化。
16. **项目的可持续性？** → 公益免费 + 增值服务 + 政府采购，商业模式与社会价值双轮驱动。

### 3.5 压力题

17. **如果试点学校反悔不配合？** → 双通道（学校团委+教育局），预案 3 所学校并行接触。
18. **如果评委说数据太少？** → 强调项目处于备赛期，已设计好完整的数据采集闭环，试点即产出。
19. **如果大厂免费开放同类功能？** → 我们的壁垒是乡村场景适配、课标对齐与教师共建生态，且公益定位与大厂商业逻辑错位。
20. **如果大赛后项目停了？** → 项目已规划 36 个月转化路径：区域试点→政府采购→公司化探索。

## 3. 命名与叙事升级

### 3.1 主标语（三选一，路演/PPT 统一）

1. 让乡村教师备课时间从 2 小时到 20 分钟（量化承诺，主推）
2. 每一节乡村课，都备得起、备得好（情怀线，结尾用）
3. 新课标落地，从一份好教案开始（政策线，BP 封面用）

### 3.2 故事线（8 分钟路演叙事）

> 遇见（调研中一位一人教三科的老师）→ 发现（备课 2~3 小时、抄教参、顾不上新课标）→ 解决（30 秒生成对齐课标的教案）→ 验证（试点数据）→ 愿景（从新乡到中西部，让每节乡村课都备得起）

## 4. 演示与视觉升级

- Demo 固定节奏：弱网手机 + 语音输入 + 流式生成 + 课标依据卡片 + 现场改要求（乡土案例）+ 导出；
- PPT 视觉规范：深绿 #2E6B4F + 麦金 #E3A03C + 米白 #F7F4EC，标题 42pt 以上、正文 18pt 以上，每页只讲一个观点；
- 一页纸项目简介（用于企业/评委/媒体），见 docs/11。

## 5. 教育维度材料清单

- 教师访谈视频/文字（授权后使用）；
- 调研问卷与数据报告（基线 vs 使用后）；
- 校媒/地方媒体报道 2~3 篇；
- 试点学校感谢信/锦旗；
- 团队实践照片（培训、驻校、田间地头）；
- 思政元素：教育公平、乡村振兴、AI 向善。

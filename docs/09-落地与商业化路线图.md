# 「杏坛智备」落地与商业化路线图（v0.1）

## 1. 落地路线图

| 阶段 | 时间 | 关键动作 | 交付物 |
| --- | --- | --- | --- |
| 备赛期 | 2026-08~2027-09 | MVP 完善、试点、材料打磨、校/省/国赛 | 名次 + 佐证材料 |

## 2. 企业合作模式与赞助回报

### 2.1 三类合作对象

| 类型 | 典型企业 | 合作方式 | 他们的收益 |
| --- | --- | --- | --- |
| 教育科技企业 | 智慧教育/大模型厂商 | 技术合作、联合试点、算力/API 赞助 | 乡村市场数据、政企背书、品牌公益 |
| 企业 CSR | 大型国企/上市公司 | 公益赞助：赞助乡村学校年费/设备 | ESG 指标、公益品牌、教师故事传播 |
| 出版/教辅企业 | 出版社、教辅公司 | 内容合作、联合教研活动 | 渠道下沉、教师触达 |

### 2.2 赞助回报设计（给企业的一页方案）

- 冠名与联合发布：试点报告、教师培训活动联合署名；
- 数据白皮书：乡村教师备课现状调研报告（企业署名）；
- 品牌曝光：校媒/地方媒体报道、路演与赛事露出；
- 公益落地：企业 CSR 项目落地学校，颁发公益证书；
- 未来合作优先权：区域推广期的优先试点权。

## 3. 投资吸引策略（投资人视角）

投资人看四个问题，我们的答案：

| 投资人问题 | 我们的答案 |
| --- | --- |
| 市场多大？ | 1069.76 万义务教育专任教师、18 万所学校；教育数字化政策持续加码 |
| 壁垒多高？ | 课标/教材知识库运营 + 教师共创数据飞轮 + 乡村场景适配，越用越难被复制 |
| 团队多强？ | 技术团队完成可运行产品；补齐商业/设计成员 + 企业顾问 |
| 数据多好？ | 试点期真实数据：备课时长下降、留存、好评率（用数据说话） |

### 3.1 融资路径

1. **公益/赞助优先**（0~50 万）：CSR 赞助、大学生创业扶持基金（河南省级）、教育公益基金；
2. **政府项目**（50~200 万）：县域教育数字化试点项目、产学研合作项目；
3. **天使轮**（200~500 万）：公司化后引入教育科技领域天使投资人。

### 3.2 融资材料清单

- 一页纸项目简介（docs/11）；
- 商业计划书（Word 版已备）；
- 路演 PPT + Demo 视频；
- 试点数据报告；
- 合规文件（软著、合作协议、授权书、AI 标识说明）。

## 4. 对接渠道

- 大赛同期投融资对接会、产教融合路演专场；
- 学校产学研合作企业名录、校友企业；
- 教育信息化展会（如中国教育装备展）与县域教育局项目；
- 省级大学生创新创业训练计划、科技型中小企业入库。

## 5. 公司化注意事项（避免法律风险）

- 公司成立前明确知识产权归属（团队/学校/企业顾问的边界），建议与学校签署成果转化协议；
- 学生团队股权结构清晰，避免"名义创始人"；
- 试点期公益免费不涉及经营性收费，合规压力小；
- 正式收费前完成：AI 服务备案、隐私政策、用户协议、内容标识。

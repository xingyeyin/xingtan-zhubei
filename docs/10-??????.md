# 「杏坛智备」法律合规手册（零风险红线）

| 事项 | 要求 | 我们的动作 |

| 生成内容标识 | 《人工智能生成合成内容标识办法》2025-09-01 施行：AI 生成内容需显式标识 | 教案页脚固定展示"本教案由 AI 辅助生成，请教师审核后使用"；导出文件同样带标识 |

## 2. 知识产权

- **代码与文档**：项目代码、文档归属团队（Git 记录完整）；软著按"独立开发"申报；
- **课标引用**：官方公开文件，合理引用并标注出处，合规；
- **教材目录**：仅存目录标题（事实信息），**严禁上传教材/课文全文 PDF**（侵犯出版社版权）；
- **教案内容**：AI 生成的教案为原创内容，不复制课文原文；
- **字体**：PPT/文档使用系统默认字体或开源字体（思源黑体等），**避免商用授权不明的字体**；
- **图片/音乐**：截图自产合规；Demo 视频背景音乐用无版权音乐或取得授权；
- **项目名称**：已做初步检索——教育类（第 41 类）存在在先注册商标"杏坛"（注册号 1985224）与"书香杏坛"（注册号 30039083）等；"杏坛智备"暂未检索到相同商标，但正式注册与对外宣传前，应委托专业机构做近似性与类别风险评估，并准备备选名称（如"杏雨智备"）。竞赛使用不受商标限制，公司化前必须完成评估。

## 3. 数据合规

- **教师信息**（手机号等属个人信息）：试点前签署《个人信息授权同意书》，明确用途与期限；
- **学生数据**：**不采集任何学生个人信息**（平台面向教师，红线）；
- **数据脱敏**：统计报表只展示聚合数据，不出现可识别个人；
- **合作协议**：试点校协议明确数据用途、存储位置、退出机制；
- **网络安全**：生产环境 HTTPS、弱口令整改、数据库备份加密。

## 4. 内容与宣传合规

- **广告法**：宣传不使用"最""第一""唯一"等绝对化用语（除非有官方证明）；"备课时间从 2 小时到 20 分钟"表述需以试点实测数据为前提；
- **竞赛诚信**：所有数据真实可溯源（统计公报、调研问卷、试点后台）；**不虚构合作单位、不夸大收入**——这是国赛最严红线，涉虚假材料将取消资格并追责；
- **引用来源**：BP/PPT 中每个外部数据标注出处。

## 5. 商业合规

- **政府采购**：区域采购需走正规招投标程序，试点期公益免费不涉及；
- **公司注册**：公司化后按规定税务登记、社保、知识产权作价入股等；
- **赞助合同**：赞助/合作均签书面协议，明确回报内容与金额（避免口头承诺）；
- **平台资质**：正式对外运营前完成 ICP 备案/等保测评评估。

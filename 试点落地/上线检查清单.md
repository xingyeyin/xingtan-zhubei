# 试点学校上线检查清单

## 一、部署与账号

- [ ] 服务器已部署（Docker 或本机），`/api/admin/ping` 可访问；
- [ ] HTTPS 生效（正式部署）；
- [ ] 大模型 API Key 有额度，测试生成 1 份教案成功；
- [ ] 管理员账号可登录管理后台；
- [ ] 演示/测试账号已清理或改密（正式环境）。

## 二、数据合规

- [ ] 试点合作协议已盖章；
- [ ] 教师《个人信息授权同意书》或协议条款确认；
- [ ] 埋点统计正常（管理端有数据）；
- [ ] 教案 AI 标识已显示（页脚）。

## 三、学校侧准备

- [ ] 学校指定对接负责人；
- [ ] 教师名单与手机号收集（用于预注册或引导注册）；
- [ ] 培训时间确定（30 分钟）；
- [ ] 调研问卷链接已准备（基线）。

## 四、运行保障

- [ ] 教师微信群建立，答疑通道通畅；
- [ ] 每周导出使用周报；
- [ ] 每月收集 1 次典型使用案例（文字/视频授权）。

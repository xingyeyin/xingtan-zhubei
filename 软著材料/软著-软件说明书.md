## 1. 软件概述

杏坛智备是一款面向乡村教师的 AI 备课助手软件，提供"新课标对齐、教材适配、即问即得"的教案生成与教研服务。教师输入学科、年级、教材版本与课题，系统通过知识库检索（2022 版课程标准、小学/初中全学段教材目录、教案模板、乡土案例）与大模型生成，输出包含教学目标、重难点、教学过程、板书设计、分层作业及课标依据卡片的完整教案，并支持 AI 追问修改、习题生成、教案导出与使用数据统计。

## 2. 主要功能

### 2.1 教师端（移动优先，H5 / 微信小程序）

1. 备课向导：分步选择学科、年级、教材版本、课题与课型，支持快捷选题；
2. AI 教案生成：调用大模型生成结构化教案，含课标依据卡片、质量评分；
3. 教案编辑器：教学目标、重难点、教学过程（时间轴）、板书、分层作业分区展示与修改；
4. AI 对话：针对教案追问、修改建议、情境导入优化；
5. 资源库：课标、教材目录、教案模板、乡土案例浏览与采纳；
6. 教案导出：Markdown 格式导出；
7. 使用统计：个人生成量与节省时长估算。

### 2.2 管理端（Web）

1. 数据仪表盘：教师数、生成量、知识库条目、节省时长、趋势图、学科分布；
2. 用户管理：教师列表、学校信息、角色与状态管理；
3. 知识库管理：课标/教材/模板/案例文档管理与分类筛选；
4. 内容审核：审核记录、四层审核机制；
5. 运营分析：近 7 日趋势、学科分布、模型配置与成本监控；
6. 系统设置：模型供应商配置、参数设置。

### 2.3 后端服务

1. 认证登录、用户与学校管理；
2. 生成任务管理：任务创建、异步执行、状态查询、失败标记；
3. 知识库检索：课标/教材/模板/案例召回与上下文拼接；
4. 大模型多供应商路由（DeepSeek / 通义千问）与结构化输出解析；
5. 使用埋点与统计聚合。

## 3. 运行与操作说明

### 3.1 环境准备

- 安装 JDK 17、Maven、Node.js 18+；
- 启动 PostgreSQL（含 pgvector）与 Redis（或使用 Docker Compose 一键启动）；
- 配置大模型 API Key（`application-local.yml` 或环境变量）。

### 3.2 教师操作流程

1. 打开教师端首页，点击"新建教案"；
2. 依次选择学科、年级、教材版本，输入课题与课型要求；
3. 点击"开始生成"，等待 AI 生成（约 20~40 秒）；
4. 在教案编辑器中查看、修改各区块，展开"课标依据卡片"核对依据；
5. 需要调整时使用"AI 对话"提出修改要求；
6. 点击"导出"保存教案。

### 3.3 管理员操作流程

1. 登录管理后台，在仪表盘查看运营数据；
2. 在"用户管理"维护教师与学校信息；
3. 在"知识库管理"维护课标、教材、模板与案例；
4. 在"内容审核"抽查生成内容；
5. 在"系统设置"配置模型供应商与平台参数。
